# 00. Подготовка и основы

[Программа курса](../README.md) · [Следующая задача](01-profile-card.md)

Цель — подготовить минимальную среду и знания, чтобы задания не превратились в копирование незнакомого кода.

## Среда и рабочий процесс

Нужны редактор, актуальный браузер с DevTools, Git и Node.js LTS для инструментов. Простую вёрстку можно открыть как файл; модули и `fetch` запускай через локальный HTTP-сервер. Например, из каталога решения: `npx --yes serve .`. Утилита загрузится из npm при первом запуске; открой адрес, который она напечатает. Для React используй Vite по инструкции в модуле 13.

Создавай файлы в UTF-8. В HTML укажи `<!doctype html>`, `lang="ru"`, `<meta charset="UTF-8">` и viewport. Подключай обычный скрипт с `defer` либо модуль через `type="module"`: код увидит разобранную разметку. DevTools: Elements показывает DOM и вычисленные стили, Console — ошибки, Network — запросы, Application — хранилище.

Git хранит историю. `git status` показывает изменения, `git diff` — разницу, `git add` готовит выбранные файлы, `git commit` фиксирует этап. Перед `git init` проверь, не находится ли каталог уже в репозитории. В npm `package.json` описывает проект и команды, lock-файл фиксирует версии зависимостей. ESLint ищет ошибки и подозрительные конструкции; форматтер отвечает за оформление. [Дока: веб-платформа и инструменты](https://doka.guide/tools/) — ищи материалы про Git, npm и сборку.

## HTML и CSS

HTML описывает смысл: заголовок, навигация, статья, форма. DOM — дерево объектов, которое браузер строит из разметки и которое меняет JS. Для перехода нужен `<a href>`, для действия — `<button>`. Семантика даёт браузеру и вспомогательным технологиям исходное поведение. Подробнее: [семантика](https://doka.guide/html/semantics/), [кнопка](https://doka.guide/html/button/).

CSS-блок состоит из содержимого, padding, border и margin. При `box-sizing: border-box` заданная ширина включает padding и border. Каскад разрешает конфликт правил с учётом происхождения, важности, слоёв, специфичности и порядка. Более позднее правило выигрывает лишь при равных предшествующих условиях. Подробнее: [box-sizing](https://doka.guide/css/box-sizing/), [Flexbox](https://doka.guide/css/flexbox-guide/).

## JavaScript: минимум до задачи 03

Примитивы: string, number, boolean, undefined, null, bigint, symbol. Объекты и массивы передаются и присваиваются как значения ссылок: две переменные могут указывать на один объект. `const` запрещает новое присваивание переменной, но не изменение свойств объекта. `let` нужен, если значение переменной меняется. Обычно сравнивай через `===`, чтобы избежать неявного приведения типов.

```js
const first = { count: 1 };
const second = first;
second.count = 2;
// Предскажи first.count, затем проверь.
const copy = { ...first };
// Это поверхностная копия: вложенный объект всё ещё может быть общим.
```

Функция принимает данные и возвращает результат; обработчик события вызывается браузером. Деструктуризация извлекает свойства, spread создаёт новую внешнюю структуру. `map` преобразует элементы, `filter` оставляет подходящие, `reduce` накапливает результат. Сначала пиши обработку данных отдельно от DOM, затем отображай результат. [Переменные](https://doka.guide/js/var-let/), [функции](https://doka.guide/js/function/), [filter](https://doka.guide/js/array-filter/).

Область видимости определяет доступ к переменным. Замыкание сохраняет доступ функции к внешнему лексическому окружению и после завершения внешнего вызова. `this` обычной функции зависит от способа вызова; у стрелочной функции берётся из окружающего контекста. Поэтому вынесенный метод может потерять контекст, а `bind` создаёт функцию с закреплённым `this`. [Области видимости](https://doka.guide/js/closures/), [контекст функций](https://doka.guide/js/function-context/).

## Входные упражнения

1. Сделай кнопку «Добавить», число и подпись. По клику число увеличивается. Сначала предскажи, что будет, если искать кнопку до разбора HTML.
2. Напиши `getActiveNames(users)`: получает массив `{ name, active }`, возвращает имена активных, исходный массив не меняет.
3. Создай `createCounter(start)`, возвращающую функцию увеличения. Два счётчика должны работать независимо.
4. Создай объект с методом, читающим `this.name`. Сравни вызов метода через объект и отдельно; исправь второй через `bind`.
5. Сверстай две кнопки в строку с `gap`, затем в колонку на узком экране.
