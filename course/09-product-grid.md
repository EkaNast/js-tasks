# 09. Адаптивная сетка товаров

[Программа](../README.md) · [Далее](10-filters.md)

Сделай каталог из шести карточек, почти без JS. В следующей задаче тот же макет получит данные через fetch.

## Теория перед работой

Flexbox удобен для строки цены и действия; Grid — для строк и колонок каталога. `repeat`, `auto-fit` и `minmax` позволяют подбирать количество колонок по свободному месту. Нижняя граница колонки не должна превышать ширину узкого контейнера; иначе сетка будет переполняться.

`aspect-ratio` задаёт пропорцию изображения, `object-fit: contain` сохраняет целый товар, `cover` обрезает края ради заполнения. Длинный текст может мешать сжатию: проверь минимальную ширину элемента и перенос слов. `clamp` ограничивает плавно меняющееся значение между минимумом и максимумом. Не обрезай название только ради одинаковой высоты: лучше выделить место и выравнивать нижнюю строку карточки раскладкой.

Прочитай [Grid](https://doka.guide/css/grid-guide/), [Flexbox](https://doka.guide/css/flexbox-guide/), [overflow](https://doka.guide/css/overflow/), [media](https://doka.guide/css/media/). Найди в гайде Grid примеры `minmax` и повторяемых колонок.

## Мини-упражнение

Размести шесть прямоугольников в Grid без фиксированной ширины карточки. Сужай именно контейнер, а не только окно. Найди ширину, на которой минимальная колонка начинает вызывать overflow, и исправь.

## Макет

```text
Каталог                                  Найдено: 6
1280px: [Карточка 1] [Карточка 2] [Карточка 3]
         [Карточка 4] [Карточка 5] [Карточка 6]
768px:   [Карточка 1] [Карточка 2]
360px:   [Карточка 1]

┌─────────────────────────────┐
│       Изображение 4:3       │
├─────────────────────────────┤
│ Наушники для работы         │

│                             │

Между карточками 24px; внутри 16px. Изображение — contain.
```

## Задание

1. Создай шесть статических товаров с разными названиями, описаниями и ценами: наушники, клавиатура, мышь, монитор, камера, лампа. Данные и цены учебные, валюта USD.
2. Используй `article`, заголовок, изображение, текстовый рейтинг и ссылку на подробное описание в нижнем блоке страницы. Не делай вложенную ссылку внутри другой ссылки.
3. Сетка подбирает колонки по контейнеру; добейся указанного числа колонок на контрольных ширинах. Карточки не имеют фиксированного `width: 320px`.
4. Нижние строки соседних карточек выровнены даже при разной длине описаний. Все данные остаются доступными.
5. Изображение с отсутствующим файлом получает понятный fallback; DOM-порядок сохраняется на всех ширинах.

## Самопроверка и ревью

- [ ] Проверены три контрольные ширины и контейнер шириной 280px.
- [ ] Название из 100 символов, большая цена и отсутствие изображения не ломают карточку.
- [ ] Изображение не растягивается, фокус ссылки виден.
- [ ] При 200% текст читается целиком; нет горизонтальной прокрутки страницы.
- [ ] Могу объяснить выбор минимальной ширины колонки.

Усложнение: переключение «сетка/список» без дублирования содержимого и сохранение выбранного режима после перезагрузки.
