# 03. Вкладки настроек

[Программа](../README.md) · [Далее](04-accordion.md)

Сделай три вкладки с управлением мышью и клавиатурой.

## Теория перед работой

Состояние компонента — идентификатор активной вкладки. Одна функция обновления должна согласованно менять панель, визуальный класс, `aria-selected` и `tabindex`. Если менять их в разных обработчиках, они могут разойтись.

Для вкладок используй `tablist`, кнопки с `role="tab"` и панели `role="tabpanel"`. Связи задают `aria-controls` и `aria-labelledby`. В группе только активная кнопка имеет `tabindex="0"`, остальные `-1`; это roving tabindex. Стрелки переводят фокус между вкладками, Tab выходит из группы. В этой задаче выбор автоматический: фокус стрелкой также активирует вкладку. Скрытые панели получают `hidden`; не переопределяй его случайно правилом `display`.

`event.target` — исходный элемент события, `currentTarget` — тот, чей обработчик исполняется. `closest` позволяет найти кнопку при клике по вложенной иконке. [События](https://doka.guide/js/events/), [closest](https://doka.guide/js/element-closest/), [aria-selected](https://doka.guide/a11y/aria-selected/). Полная модель: [WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/).

## Мини-упражнение

В кнопку вложи `span`. Повесь обработчик на общий контейнер и выведи `target` и `currentTarget`. Сравни клик по тексту и свободной области кнопки.

## Задание

1. Сделай три панели с разным текстом и хотя бы одной кнопкой или ссылкой в каждой. Изначально активно «Общее».
2. Клик, ArrowLeft/ArrowRight с циклическим переходом, Home/End выбирают вкладку. Для обработанных стрелок предотвращай прокрутку.
3. Скрывай остальные панели и исключай их содержимое из клавиатурного обхода. Видимая панель должна быть доступна после группы вкладок; при необходимости добавь ей `tabindex="0"`.
4. Подписывайся один раз на контейнер группы, определяй выбранную кнопку через `closest` и её `data-*`.

## Самопроверка и ревью

- [ ] Во всех способах переключения ровно одна активная вкладка и видимая панель.
- [ ] Tab не посещает три кнопки подряд, стрелки работают по кругу.
- [ ] Фокус виден отдельно от индикатора выбора.
- [ ] Нажатие по вложенному тексту работает; клик по пустому месту ничего не выбирает.
- [ ] После 20 переключений не возникает дополнительных обработчиков.

Усложнение: две независимые группы вкладок на одной странице с уникальными ID.
