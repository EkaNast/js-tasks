# 06. Диалог подтверждения

[Программа](../README.md) · [Далее](07-toast-manager.md)

Сделай подтверждение удаления учебного проекта. Все изменения происходят только в данных страницы.

## Теория перед работой

`dialog.showModal()` открывает нативный модальный диалог в верхнем слое браузера и делает остальной документ неинтерактивным. `show()` создаёт немодальный диалог. Просто нарисованный поверх страницы блок этих свойств не получает.

`::backdrop` оформляет фон. Фокус должен попасть на подходящее действие; в опасном подтверждении выбирай «Отмена». После закрытия верни его инициатору, если тот существует; после удаления инициатора — следующему логичному элементу. Нативный диалог обеспечивает модальность, но разумные начальный и конечный фокус проверяешь ты. Escape инициирует `cancel`, а завершение закрытия — `close`. Отмена не равна подтверждению.

Прочитай [dialog](https://doka.guide/html/dialog/), [button](https://doka.guide/html/button/), [z-index](https://doka.guide/css/z-index/). Для общей модели фокуса: [WAI-ARIA Modal Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

## Мини-упражнение

Открой один диалог через `show`, другой через `showModal`. Проверь Tab, возможность нажать фоновую кнопку и Escape. Запиши различия своими словами.

## Макет

```text
Фон: список проектов
  Учебный каталог                      [Удалить]

           затемнённая подложка
       ┌─────────────────────────────┐
       │ Удалить проект?             │
       │ «Учебный каталог» исчезнет  │
       │ из списка на этой странице. │
       │                             │
       │ [Отмена]         [Удалить]  │
       └─────────────────────────────┘
Диалог до 420px; на телефоне кнопки могут быть в колонке.
```

## Задание

1. Покажи два проекта с кнопками удаления. Один общий `dialog` подставляет название выбранного проекта; свяжи диалог с заголовком через `aria-labelledby`.
2. Открывай через `showModal`, начальный фокус — на «Отмена». Клик по ней и Escape закрывают без удаления.
3. Подтверждение удаляет ровно выбранный проект и выводит статус на странице. Сохраняй его ID в состоянии, а не извлекай по позиции строки.
4. Закрытие кликом по подложке в основной версии отключено. Клик внутри также не закрывает окно.
5. Если инициатор удалён, переведи фокус на кнопку следующего проекта либо заголовок списка с программным `tabindex="-1"`.

## Самопроверка и ревью

- [ ] Фон недоступен мышью и Tab, название проекта верно.
- [ ] Отмена и Escape не удаляют данные; подтверждение не выполняется дважды.
- [ ] В диалоге есть доступное имя и видимый фокус.
- [ ] После закрытия фокус находится в предсказуемом месте.
- [ ] При 200% окно помещается по ширине, содержимое доступно прокруткой по высоте.

Усложнение: реализуй Promise-API `confirmDelete(project)`, возвращающее `true` или `false`; параллельные вызовы должны обрабатываться последовательно.
