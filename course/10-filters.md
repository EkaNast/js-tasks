# 10. Фильтры каталога и URL

[Программа](../README.md) · [Далее](11-data-table.md)

Подключи каталог к API и добавь поиск, категории, цену и сохранение состояния в URL.

## Теория перед работой

Исходный массив сохраняй отдельно. `filter` возвращает новый массив; порядок условий не должен менять смысл: поиск, категория и цена объединяются через «и». Сортировку делай по копии, поскольку `sort` меняет исходный массив. Числовые цены сравнивай численно, строки — через `localeCompare`. [Filter](https://doka.guide/js/array-filter/), [sort](https://doka.guide/js/array-sort/).

URL делает выбор воспроизводимым: ссылку можно отправить и открыть заново. `URLSearchParams` читает строковые значения — числа и допустимые категории нужно валидировать. `history.pushState` создаёт запись истории без загрузки страницы, `replaceState` заменяет текущую. Событие `popstate` позволяет восстановить экран при Назад/Вперёд. [URLSearchParams](https://doka.guide/js/urlsearchparams/).

`localStorage` хранит строки между сессиями, `sessionStorage` — в рамках сессии вкладки. Для объектов нужны JSON.stringify/parse, чтение может завершиться ошибкой. В этой задаче URL отвечает за фильтры, localStorage — только за режим отображения, чтобы не было двух конфликтующих источников. [LocalStorage](https://doka.guide/js/local-storage/).

Перед реализацией прочитай [практику API](api-practice.md) и [Доку о fetch](https://doka.guide/js/fetch/).

## Мини-упражнение

Напиши чистую `filterProducts(products, filters)`. Проверь на трёх объектах: одинаковые категории, цена 0, цена на границе диапазона. После вызова исходный массив должен остаться неизменным.

## Макет

```text
Каталог                    [Сетка] [Список]
Загружено N из total товаров
┌──────────────────┐ ┌──────────────────────────┐
│ Поиск [________] │ │ Найдено: M               │
│ Категория [Все▼] │ │ Порядок [Цена ↑       ▼] │
│ Цена до [______] │ │ [Товар] [Товар] [Товар]  │
│ [Сбросить]       │ │ [Товар] [Товар] [Товар]  │
└──────────────────┘ └──────────────────────────┘
360px: фильтры над результатами, одна колонка карточек.
Загрузка: «Загружаем каталог…»
Ошибка: «Не удалось загрузить» [Повторить]
Нет совпадений: «Ничего не найдено» [Сбросить фильтры]
```

## Данные

Получай через fetch `https://dummyjson.com/products?limit=100&select=id,title,price,category,rating,stock,thumbnail`. Коллекция находится в `products`; отображай фактические `title`, `price`, `rating`, `thumbnail`. Категории получи из уникальных `category` загруженной выборки. Валюта учебного каталога — USD. Не придумывай категории, которые не представлены в данных. [Контракт API](https://dummyjson.com/docs/products).

## Задание

1. Покажи loading/error/success и повтор загрузки. Работай со всеми загруженными записями, укажи ограничение выборки. После загрузки поиск по подстроке title без учёта регистра, категория и максимальная цена фильтруются локально.
2. Цена включает границу; пустое поле не ограничивает её. Отрицательная или нечисловая цена даёт ошибку поля и не применяется.
3. Добавь сортировку `price-asc`, `price-desc`, `title-asc`. Не меняй исходную коллекцию. Счётчик показывает число совпадений текущих фильтров.
4. Синхронизируй `q`, `category`, `maxPrice`, `sort` с URL, например `?q=phone&sort=price-asc`. Defaults в URL можно опускать. Прочитай URL при запуске и после `popstate`.
5. Для явных изменений категории, сортировки и сброса используй pushState; для набора текста — replaceState, чтобы история не содержала каждую букву. Другие параметры страницы сохраняй.
6. Сделай режим «сетка/список» и сохрани его в localStorage. Некорректная запись хранилища или параметр URL возвращают безопасный default.

## Самопроверка и ревью

- [ ] В Network есть загрузка данных; Offline и «Повторить» проверены.
- [ ] Цена 0 не трактуется как отсутствие фильтра; пустой поиск показывает всю выборку.
- [ ] Ссылка с фильтрами после перезагрузки даёт те же элементы управления и результаты.
- [ ] Назад/Вперёд восстанавливают выбор; категория проверяется после загрузки данных.
- [ ] Строка с `&` кодируется верно; невалидная цена не портит URL.
- [ ] После сброса нет старых фильтров; режим сетки при этом сохраняется.

Усложнение: добавь группировку по категории через `reduce` и покажи количество совпадений в каждой группе.
