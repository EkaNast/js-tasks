# Практика API: fetch и DummyJSON

[Программа](../README.md) · Используется в задачах [08](08-autocomplete.md), [10](10-filters.md), [11](11-data-table.md), [12](12-mini-dashboard.md)

Публичный учебный сервис [DummyJSON](https://dummyjson.com/docs) предоставляет GET-запросы товаров и пользователей без ключа. В курсе используем только чтение. Контракты взяты из [документации товаров](https://dummyjson.com/docs/products) и [пользователей](https://dummyjson.com/docs/users). Число записей и конкретные названия не фиксируй в коде: набор данных может измениться.

## Теория

HTTP-запрос состоит из метода, адреса, заголовков и при необходимости тела. GET читает ресурс. REST обычно представляет сущности через адреса ресурсов и HTTP-методы. Статусы 2xx сообщают об успехе, 4xx — о проблеме запроса, 5xx — о проблеме сервера.

`fetch` возвращает Promise объекта Response. Даже при 404 или 500 Promise обычно успешно разрешается: проверяй `response.ok`, затем отдельно вызывай асинхронный `response.json()`. Сетевой сбой и отмена могут отклонить Promise. JSON нужно проверить: минимум убедись, что нужная коллекция — массив. Поле `total` в ответе не равно длине текущей страницы. [Дока: fetch](https://doka.guide/js/fetch/), [Promise](https://doka.guide/js/promise/), [async/await](https://doka.guide/js/async-await/).

Для параметров используй [URLSearchParams](https://doka.guide/js/urlsearchparams/), чтобы пробелы, `&` и другие символы корректно кодировались. Для отмены — [AbortController](https://doka.guide/js/abort-controller/). Код обработки данных не должен знать, где расположены кнопки: функции API возвращают данные, UI отображает их.

Запускай страницу через локальный HTTP-сервер. CORS — разрешение сервера на чтение ответа с другого origin, а не настройка, которую можно отменить на клиенте. `mode: 'no-cors'` даёт непрозрачный ответ и не решает задачу чтения JSON. Cookies передаются по своим правилам и могут участвовать в авторизации; в этом курсе не нужны cookies, токены и `credentials: 'include'`. Подробнее о сети ищи в [разделе веб-платформы Доки](https://doka.guide/tools/).

## Контракты для заданий

| Задача | Запрос относительно `https://dummyjson.com` | Что использовать |
|---|---|---|
| 08 | `/products/search?q=phone&limit=5` | `products`: `id`, `title` |
| 10 | `/products?limit=100&select=id,title,price,category,rating,stock,thumbnail` | `products` для локальных фильтров |
| 11 | `/users?limit=100&select=id,firstName,lastName,email,role,age` | `users` для локальной таблицы |
| 12 | Два предыдущих запроса | Две независимые секции |

`limit=100` — осознанное ограничение учебной выборки. В задачах 10 и 11 покажи «Загружено N из total». Фильтрация и пагинация основной версии работают только по загруженным N записям; не выдавай их за поиск по всей базе.

## Мини-упражнение перед задачей 08

Сделай страницу с кнопкой «Загрузить 5 товаров», статусом и списком. Используй `/products?limit=5`. По клику установи loading, выполни fetch, проверь HTTP-статус, прочитай JSON, выведи названия через `textContent`. При ошибке покажи текст и «Повторить». Во время загрузки не запускай второй такой же запрос. Это отдельное упражнение, а не готовая реализация autocomplete.

## Как проверять

1. В Network посмотри URL, метод GET, статус, payload ответа и время. Проверь, что вместо массива приходит объект с коллекцией.
2. Включи Slow 3G, проверь loading. Включи Offline, дождись ошибки, верни Online и нажми «Повторить».
3. Для HTTP-ошибки временно запроси `/products/999999`, проверь обработку неуспешного статуса, затем верни рабочий URL.
4. Для пустого результата поиска передай уникальную бессмысленную строку. Для некорректного JSON или порядка ответов подставь локальную тестовую функцию: внешний сервис не обязан воспроизводить эти случаи.
5. Не проверяй точные имена и количество данных сервиса; проверяй контракт и поведение страницы.

## Ограничение проверки материалов

Документация DummyJSON проверена при подготовке курса. Прямые запросы из рабочей среды автора были недоступны из-за сетевого ограничения, поэтому live-ответы здесь не заявлены как проверенные. Первый шаг ученика — мини-упражнение и проверка Network. Если сервис временно недоступен, можно продолжить с локальной фикстурой, но для сдачи API-задач всё равно продемонстрируй настоящий fetch.
