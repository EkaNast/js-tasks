# 05. Центр уведомлений

[Программа](../README.md) · [Далее](06-modal.md)

Сделай кнопку с количеством непрочитанных и выпадающую панель уведомлений.

## Теория перед работой

Абсолютно позиционированная панель размещается относительно содержащего блока; для обычного случая его создаёт ближайший предок с `position: relative`. `max-height` и `overflow-y: auto` ограничивают длинный список. `z-index` сравнивается внутри контекстов наложения: большой номер потомка не позволяет выйти над соседним контекстом предка. [Position](https://doka.guide/css/position/), [overflow](https://doka.guide/css/overflow/), [z-index](https://doka.guide/css/z-index/).

При всплытии событие идёт от исходного элемента к предкам. Делегирование — один обработчик на списке, который находит нужную кнопку через `closest`. Оно работает и для элементов, добавленных позже. Не всякое событие всплывает; для `click` этот подход подходит. [События](https://doka.guide/js/events/), [closest](https://doka.guide/js/element-closest/).

Храни `{ id, title, time, read }` в массиве, а счётчик вычисляй из него. Повторный клик по прочитанному не должен уменьшать счётчик. Кнопка раскрытия получает `aria-expanded` и `aria-controls`; панель содержит список обычных кнопок, поэтому роль `menu` ей не нужна. [Aria-expanded](https://doka.guide/a11y/aria-expanded/).

## Мини-упражнение

Создай список с одним обработчиком. Добавь новую кнопку после подписки; проверь, что нажатие на неё и вложенную иконку определяется корректно. Выход за пределы нужного списка отсекай проверкой принадлежности.

## Макет

```text
Панель приложения                    [🔔 2]
                        ┌──────────────────────┐
                        │ Уведомления           │
                        │ ● Сборка завершена    │
                        │   2 минуты назад      │
                        │ ● Вас упомянули       │
                        │   10 минут назад      │
                        │   Публикация успешна  │
                        │ [Прочитать все]       │
                        └──────────────────────┘
Панель до 360px, справа под кнопкой; на 360px экрана
не выходит за боковые поля. Список — до 320px по высоте.
```

## Задание

1. Начальные данные: три записи с ID `n1`, `n2`, `n3`; первые две непрочитанные. Счётчик изначально равен 2.
2. Кнопка открывает и закрывает панель. Escape и клик снаружи закрывают её; клик внутри не закрывает. Для проверки внешнего клика используй `contains` на обёртке кнопки и панели.
3. Клик по записи отмечает её прочитанной и обновляет счётчик. «Прочитать все» обнуляет его. При нуле показывай понятное состояние без значка непрочитанности.
4. При открытии фокус остаётся на кнопке, Tab переходит к действиям панели. Escape возвращает фокус на кнопку. Внешний клик сохраняет естественный фокус выбранного пользователем элемента.
5. Создай также пустой список и список из 30 записей для проверки. Скрытая панель не участвует в Tab.

## Самопроверка и ревью

- [ ] Открытие не отменяется обработчиком внешнего клика в том же событии.
- [ ] Повторная отметка не делает счётчик отрицательным.
- [ ] Панель не обрезается предком с overflow и не выходит за экран.
- [ ] Escape, Tab, пустой список и длинный заголовок работают.
- [ ] 20 открытий не создают 20 подписок; есть способ удалить подписки при уничтожении компонента.
