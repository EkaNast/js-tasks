# Практический курс Frontend: Junior → Junior+

Курс создан по [proto.txt](proto.txt). Результат — 12 работающих интерфейсов и их перенос в React + TypeScript. Основной путь: HTML → CSS → JavaScript → DOM → доступность → браузерные API → React. Готовых решений нет: теория, маленькие упражнения и проверяемые требования помогают написать код самостоятельно.

## Как проходить

1. Пройди [подготовку](course/00-foundations.md). Если уже знаешь основы, выполни входную проверку.
2. Для каждой задачи прочитай короткую теорию и указанные статьи [Доки](https://doka.guide/), затем сделай мини-упражнение.
3. Сверстай схему, добавь поведение, проверь обычные и крайние случаи. Перед задачей 08 пройди [практику fetch и открытого API](course/api-practice.md): дальнейшие поиск, каталог, таблица и дашборд используют DummyJSON.
4. Ответь на вопросы вслух и проведи саморевью.
5. После всех задач выполни [перенос в React + TypeScript](course/13-react-typescript.md). Переносить можно по одному компоненту после изучения этого модуля.

Начальная версия каждого задания — обычные HTML/CSS/JS без React, UI-библиотек и готовых реализаций нужного компонента. В задачах 01 и 09 JavaScript не обязателен. Объём курса можно распределять по своему темпу; оценка часов не является сроком сдачи.

## Что означает 💡

💡 отмечает темы из опубликованных подборок вопросов для frontend-собеседований. Формулировки адаптированы к заданиям. Источник указан рядом: [H5BP: JavaScript](https://h5bp.org/Front-end-Developer-Interview-Questions/questions/javascript-questions/), [H5BP: CSS](https://h5bp.org/Front-end-Developer-Interview-Questions/questions/css-questions/) или рубрика «На собеседовании» в Доке. Это подтверждает наличие темы в материалах для интервью, но не гарантирует конкретный вопрос в конкретной компании. Упражнения и дополнительные вопросы курса составлены для обучения.

## Общие правила макетов

Схемы в блоках `text` задают структуру и содержимое. Они не требуют копирования количества пробелов. Если задача не переопределяет параметры: фон #f5f7fb, поверхность #fff, текст #182230, акцент #2563eb; системный шрифт 16px/1.5; шаг отступов 8px; рамка 1px; радиус 12px. Контейнер до 1120px, боковые поля 16px на телефоне и 24px на широком экране. Видимый фокус обязателен, цвет не должен быть единственным обозначением состояния.

Проверяй ширины 360, 768 и 1280px, масштаб 200%, длинный текст и клавиатуру. Горизонтальная прокрутка всей страницы недопустима. Для таблицы разрешён отдельный прокручиваемый контейнер. У интерактивных элементов должны быть понятные имена; кнопка с одной иконкой получает доступное название.

## Что сдавать

Для каждой задачи создай `solutions/NN-name/` с `index.html`, `styles.css`, при необходимости `main.js`, данными и своим `README.md`. Опиши запуск, выполненные требования, проверки и известные ограничения. Не коммить `node_modules`, пароли или ключи. Сделай отдельный Git-коммит на законченный этап.

Задача закончена, когда выполнены обязательные требования, самопроверка проходит, нет неожиданных ошибок в консоли, а ты можешь объяснить переход «действие → состояние → интерфейс». Усложнения факультативны. Не нужно добавлять все усложнения, чтобы перейти дальше.
